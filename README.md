# TiaozinGPT

Chat com inteligência artificial feito em HTML, CSS e JavaScript, usando a API da Groq. Projeto da disciplina de Desenvolvimento Web (DW1).

Site publicado: https://tiaozin.github.io/Chat_IA-DW1/

## Integrantes

- Sebastião Marcos Pereira da Silva

## API utilizada

- **API:** Groq
- **Modelo:** openai/gpt-oss-120b
- **Documentação:** https://console.groq.com/docs

## Como executar

1. Crie uma API Key gratuita em https://console.groq.com/keys

2. Baixe o projeto:

   ```bash
   git clone https://github.com/Tiaozin/Chat_IA-DW1.git
   ```

3. Abra o arquivo `index.html` no navegador. Não é preciso instalar nada.

4. Cole a sua API Key no campo "API Key" do menu lateral e comece a conversar.

Também é possível usar direto pelo link do site publicado, acima.

A chave não fica salva: ela precisa ser colada de novo sempre que a página for recarregada.

## Funcionalidades

- Várias conversas, com lista no menu lateral
- Histórico salvo no navegador
- Respostas formatadas em Markdown
